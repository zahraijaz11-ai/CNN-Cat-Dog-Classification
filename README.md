# Cat vs Dog Image Classification

A deep learning image classification project that classifies images as either a Cat or Dog.

## Model

The project uses **MobileNetV2**, a Convolutional Neural Network (CNN), with transfer learning.

## Dataset

The dataset contains approximately 25,000 cleaned cat and dog images.

The dataset is not included in this repository because of its large size.
